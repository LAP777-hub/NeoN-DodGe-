# NeoN-DodGe-

**Dodge. Survive. Beat the High Score.**

NeoN-DodGe- is a browser-based arcade game built around quick reflexes, precision, and survival. Players must navigate through incoming obstacles, avoid collisions, and challenge themselves to achieve the highest possible score.

The project focuses on delivering an engaging, responsive, and enjoyable gaming experience with a clean interface and a neon-inspired visual identity.

## 🎮 About the Game

NeoN-DodGe- is designed to provide a simple but challenging arcade experience. As the game progresses, players must remain alert, react quickly, and develop better strategies to survive longer and improve their scores.

Whether you're playing casually or competing for the highest score, the objective remains simple:

**Dodge the obstacles and beat the high score!**

## ✨ Features

- Interactive arcade-style gameplay.
- Obstacle avoidance and survival mechanics.
- Score tracking and high-score challenges.
- Neon-inspired user interface.
- Responsive game interface.
- Database integration with Supabase (planned/in development).

## 🛠️ Technology Stack

The project is built using modern web technologies:

- **TypeScript** – Application logic and type safety.
- **React** – Component-based user interface.
- **Vite** – Development environment and build tooling.
- **Tailwind CSS** – Styling and interface design.
- **Supabase** – PostgreSQL database and backend services.

## 🗄️ Database

Supabase is intended to provide the backend infrastructure for player-related data, including:

- Player profiles.
- Game scores.
- High-score records.
- Leaderboard rankings.
- Game session statistics.

Database functionality is currently in development.

## 🚀 Getting Started

### Prerequisites

- Node.js (LTS recommended).
- npm.
- A Supabase account (for backend functionality).

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/LAP777-hub/NeoN-DodGe-.git
   ```

2. Navigate into the project directory:

   ```bash
   cd NeoN-DodGe-
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite in your browser.
